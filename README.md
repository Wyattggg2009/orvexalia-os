# Orvexalia OS — Genesis v0.1

An independent, static, browser-only starter for eight connected systems. No installation or account required to preview it. The seven domain applications and the operating system desktop provide navigation and local sample record creation, editing and deletion, application search, and JSON export. This is not a secure or multi-user app; do not enter private information. The master console is a demonstration, not a protected administrator account. All emergency, city, intelligence and business activities are fictional simulations. External integrations are placeholders only.

## Publish with GitHub Pages

1. Create a new repository named `orvexalia-os` on GitHub. Choose repository visibility appropriate for your account and intended deployment. Do not put secrets or personal information in the repository.
2. Upload `index.html` and this README to the root of the repository; commit the changes.
3. Open repository Settings > Pages. If available, choose Deploy from a branch, main, and /(root), then Save.
4. Open the Pages URL shown by GitHub when the deployment is ready.

You can also open index.html directly in a browser; local storage availability for local files varies by browser. No database is included in this prototype.

## Planned next stages

- Shared authentication, per-module roles, database-enforced permissions and audit trail, separate private relationship/family data, secure file storage and notifications.
- Application-specific data models and workflows; real-time internal messaging; simulated economy with auditable transactions.
- Integrate existing projects only after reviewing their authentication, schemas and access policies. Keep them unchanged until integration is tested.
- Add independent module enable/disable settings and mobile/tablet layouts.

Do not use this prototype for real financial, emergency or intelligence operations. Do not store passwords, payment details or other sensitive information in browser local storage. A production build requires a separate secured backend and testing.
